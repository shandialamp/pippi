# Pippi

一个功能强大的 Go 工具库集合。

## 模块

### Collection

类似 Laravel Collection 的 Go 泛型集合库，提供丰富的数据处理方法。

```bash
go get github.com/shandialamp/pippi/collection
```

[查看完整文档](collection/README.md)

### Exception

错误处理库，将标准 Go 错误与 `zap` 结构化日志字段相结合。

```bash
go get github.com/shandialamp/pippi/exception
```

[查看完整文档](exception/README.md)

### Ptr

指针工具库，为基础数据类型提供方便的指针转换函数。

```bash
go get github.com/shandialamp/pippi/ptr
```

[查看完整文档](ptr/README.md)
